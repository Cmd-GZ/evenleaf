# 排版与写作手册

> 本手册承接 [`AGENTS.md`](../AGENTS.md) 的全局规范，专门收录 XeLaTeX 排版避坑指南、标准写作模板、交付校验清单、提交流程与新书立项步骤。

## 1. XeLaTeX 排版陷阱（按症状检索）

| 症状 / 报错 | 根因 | 处理办法 |
|---|---|---|
| `ExtGState 'pgf@CA0.55' is unknown`，半透明糊成实心 | `xdvipdfmx` 透明度支持异常 | 全书禁用 `opacity`、`fill opacity`、`transparency group`；需要浅淡效果时预先算出混色实值（如 `cover.tex` 中的 `cv30`、`cv55`） |
| 封面背景或定位图形偏移、目录为空 | `remember picture` 与 `.toc` 未稳定 | 必须至少运行三遍 `xelatex`（`./build.sh` 已固化 `PASSES=3`），严禁拿单遍编译结果作判据 |
| `Missing \begin{document}` 或 `\ttl@format@iii` 报错 | `titlesec` 的 `\titleformat` 可选参数被 `]` 提前截断 | `after` 参数段中不写任何方括号，装饰元素封装成独立宏后再以 `[\chapterornament]` 调用 |
| 页眉横线仍在但文字消失，或全局页眉被清空 | `fancyhdr` v5 与派生页眉样式冲突 | 避免用 `\fancypagestyle` 定义派生样式，直接编写 `\ps@plain` 与 `\ps@frontmatterpage` |
| 版权页或扉页末尾 `\vfill` 导致凭空多出一页 | 固定高度盒子叠加 `\vfill` 溢出版心 | 整页内容装入 `minipage[t][\dimexpr\textheight-24pt\relax][s]`，预留 `24pt` 余量 |
| 前置页阿拉伯/罗马页码意外跳变 | `titlepage` 与 `\frontmatter` 默认重置页码 | 不用 `titlepage`，统一 `\thispagestyle{empty}` + `\clearpage`；切换正文时手工执行 `\@mainmatterfalse` / `\@mainmattertrue` 与 `\pagenumbering` |
| `\tableofcontents` 自动强行新起一页 | 标准书类默认分页 | 自行排版标题后调用 `\csname @starttoc\endcsname{toc}`（`lof`、`lot` 同理） |
| `①②ⅠⅡ` 等符号出现 `Missing character` | 这些码位不在常规 CJK 区块，xeCJK 默认交由西文字体 | 保留 `shared/style/series-base.tex` 中的 `\xeCJKDeclareCharClass` 声明 |
| 长西文专名或编号撑破版心触发 `Overfull` | 连续西文无断行点 | 在合适音节插入 `\-` 软断点，或微调句序 |
| `longtable` 表格超出版心宽度 | 忘记计入列间距 `2 × \tabcolsep × 列数` | `\textwidth` 为 `147 mm`，配比各 `p{}` 列宽时扣足列间距并在两端加 `@{}` |
| 章节标题后第一段失去首行缩进 | `titlesec` 默认抑制首段缩进 | 中文书惯例凡自然段皆缩进（仅跨页续排段不缩进），基座已设置 `\@afterindenttrue`，勿改回；`\par` 后接中文必须作 `\par{}` |
| EAN-13 条码文字竖排错位 | 默认锚点受字高影响 | 统一使用 `anchor=base` 将文字基线钉在坐标上；更换 ISBN 后必须同步重算 95 模块 30 段并更新扉页/CIP、封底与本书宏 |

## 2. 标准写作与图版模板

### 2.1 章首与节结构

```latex
\chapter{章名}
\chaptersubtitle{ГЛАВА ПЯТАЯ}{俄文副题}   % 俄文原著用双行
\chapterkana{月の裏側の城}                  % 日文原著用单行
\epigraphbox{“引文”}{——出处}
\kaishou{两三行提要。\par{}全书唯一允许带作者语气的正文位置。}
\section{小节名}
正文……\footnote{真实文献：卷次、点校本、页码；或档案编号。}
```

- 副题语言随原著走，日文原著勿配俄文副题。
- 题记取真实传世诗文，宜与本章荒谬命题形成结构反讽。
- 概论体通常不另设僵化的「本章结论」固定标题，而在末尾一节作推理盘点与限度自白；专论体可按自身体例设置，各章收束句式不得雷同。

### 2.2 脚注与档案框

- **脚注**：依托 `footmisc` 的 `perpage` 逐页重置；单条不超过四行；格式遵循「真实文献出处 + 一句冷静注语」，详见 `meta/写作规范.md`。
- **档案框**：
  ```latex
  \begin{archive}[内部参考]{档案 № ФВ-1971-22}
  冷静的移交或观测记录：物件、尺寸、编号、成分，必要时保留涂抹或残缺痕迹。
  \end{archive}
  ```
  新增 `ФВ-年份-序号` 前必须全仓库检索，确保编号与材料本身年份全局唯一，并同步登记至本书 `SETTING.md`。

### 2.3 图与表

- 图表整幅高度不超过 `11 cm`，防止整页浮动；TikZ 绘图先用 `\useasboundingbox` 固定画布，线条使用黑白灰阶（线宽 `0.3–0.9 pt`），浮动参数用 `[htbp]`，不用 `[H]`。
- 表格一律采用 `booktabs`，禁画竖线；表题在上，`\tabsource{}` 在下；千分位分隔写作 `{,}`（如 `27{,}800`），幂次写作 `\textsuperscript{}`。修改任意数字后须全书（及跨书关联处）检索对齐。

## 3. 交付前自检清单

- [ ] 运行 `./build.sh`：确认 **未解析引用 = 0、缺字 = 0、Overfull = 0**，页数符合预期。
- [ ] 检查生成的 PDF：封面与封底定位正常、页眉文字无缺失、目录与图表目录页码对齐。
- [ ] 若改动章节增删或导致跨页移动，必须重新按实际 PDF 页码核校书末索引与版权页「印张 / 千字」（印张 = 总页数 ÷ 16 保留两位小数；字数按实际正文千字估算）。第 XIII 卷的索引可用 `python3 scripts/build-index.py` 校正（默认读取 `books/mooncity/`）：它对每个条目在 ±10 页内找真正出现该词的那一页，只挪页码、不重选页；加 `--write` 才回填。改完再跑一次应当报「需要改 0 条」。
- [ ] 全文检索禁用模板词与未清理痕迹（如 `??`、`未损`、`原为`、`已改为`、`后文所说的`、`如前所述`、`显然`、`众所周知`、`认账`、`先讲清楚` 等），确认为空。
- [ ] 检查 `git status`：只保留 `*.tex` 与 `*.md`；`*.pdf`、`*.aux`、`*.log` 一律不入库，PDF 由 CI 发布到 Release。

## 4. 提交与新书立项

### 提交规范

- 提交信息使用中文：首行简明概括本次动作，空一行后说明改动原因与校验结果。
- 内容修订与版式改动尽量分次提交；改动版式基座 `shared/` 后须重新编译仓库内所有成书。
- 源码变更后无需提交 PDF：CI 会以 `build-YYYY-MM-DD-<sha>` 标签新建一次 Release，三卷成品作为资产上传，最新一次构建即 GitHub 意义上的 latest release，历史构建随时可取。

### 取回成品 PDF

PDF 不入库，要取本地产物用 [`scripts/fetch-pdfs.sh`](../scripts/fetch-pdfs.sh)：它把 Release 标签里的提交号与本地「最近一次改动构建输入」的提交比对，一致才下载回 `books/<卷>/` 下的分发文件名。

```bash
./scripts/fetch-pdfs.sh            # 核对版本后下载
./scripts/fetch-pdfs.sh --check    # 只报告状态，不下载
./scripts/fetch-pdfs.sh --force    # 跳过版本核对，直接下载最新一次构建
./scripts/fetch-pdfs.sh --wait 300 # 该提交的构建还在排队或运行时，最多等 300 秒
```

- 构建输入的路径范围与 `render.yml` 的 `paths` 逐条一致（`books/**/*.tex`、`books/*/build.sh`、`shared/`、`texmf/`、`.github/workflows/render.yml` 自身），改 `PLAN.md`、`SETTING.md`、`TODO.md` 或其它工作流都不算「本地领先」。
- 退出码：`0` 已对齐（`--check` 到此为止）；`1` 取不到本地提交，或有文件下载失败；`2` 取不到 Release（参数不认识同样返回 2）；`3` 远端还停在旧提交（附该提交的 Actions 状态提示，便于区分「还没轮到」与「编挂了」）。
- 版本闸只读提交历史：`touch` 或工作区里改而未提交的 `.tex` 不会让它判成「本地领先」，要等改动提交并推送后脚本才会报 `3`。
- 资产名取卷目录名（`books/foo/` → `foo.pdf`），落盘时改名成该卷 `build.sh` 里 `DIST="..."` 指定的分发文件名；没有 `build.sh` 的目录、或 Release 里缺对应资产的卷会跳过。
- 依赖 `curl` 与 `python3`；公开仓库不需要 token，设 `GITHUB_TOKEN` 只为提高 API 速率上限。

### 新增一本书

> 只要新书目录里带 `build.sh`，CI 会自动编译、校验并作为资产发布到 Release，资产名取目录名（`books/foo/` → `foo.pdf`）。新增书目不需要改工作流。


1. 先核对 [`worldview/`](../worldview/) 大事记与核心规则，确认新书对应的时段与事件无设定冲突。
2. 确定全书体裁（概论、辑佚考释、年谱或档案汇编），避免拿错模板骨架。
3. 以现有成书（如 `books/mooncity/` 或 `books/guanghan/`）为基础拷贝目录，保留 `build.sh` 与 `preamble.tex` 外壳，清空旧正文；版权页直接调用 `shared/style/series-frontmatter.tex` 的 `\copyrightpage` 宏（`books/warthunder/` 尚待重写且未迁移至此宏），本书特有样式只覆写在自身 `preamble.tex` 中。
4. 编写本书专属 `SETTING.md` 与 `PLAN.md`，登记专属数字、专名、档案编号与章节主证物；同步更新 `meta/丛书书目.md` 与 `meta/当前状态.md`。
